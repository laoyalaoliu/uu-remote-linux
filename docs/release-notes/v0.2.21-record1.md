基于上游 v0.2.21 之后的主线（尖端 95e416e），新增把远程桌面会话录制为 MP4 的功能。/ Based on upstream main after v0.2.21 (tip 95e416e), adding MP4 recording of remote desktop sessions.

### 新增 / Added
- **远程桌面录制为 MP4（`UU_RECORD_DIR`）**：在被控的 Linux 机器上设置该变量后，每次远程会话自动录制，
  会话结束成片，文件名为 `uu-remote-<时间>-<编码>.mp4`，可直接播放或下载；不设该变量则完全不录，
  行为与原版一致。
  Setting `UU_RECORD_DIR` on the controlled machine records each desktop session to MP4
  (`uu-remote-<time>-<codec>.mp4`); unset, nothing is recorded and behavior is unchanged.
- 录制是无损的：直接复用已编码的视频流，不重新编码，不影响远控流畅度；录制失败只记日志，
  绝不中断会话。只录画面，不录声音。
  Recording is lossless (it taps the already-encoded stream, no re-encoding) and a recording
  failure is only logged, never interrupting the session. Video only, no audio.
- 常驻服务用法：在 systemd 单元里加 `Environment=UU_RECORD_DIR=%h/uu-recordings`。
  H.265 录像建议用 VLC 播放；想最大兼容，强制 `UU_VIDEO_CODEC=h264`。

### 说明 / Notes
- 本版同时包含上游 v0.2.21 之后主线的改进，包括 inproc-av 的原生 VAAPI / NVENC
  （XShm 直读、4:4:4）与设备能力格式列表等。
- ⚠️ 录制功能为代码层面验证：212 个测试全过，另有合成画面录制验证了 MP4 时长；
  **尚未用真实 UU 客户端端到端实测**，第一次使用时请确认录像文件正常生成。
  Recording is verified at code level only (212 tests passed, plus a synthetic-frame recording
  validating MP4 duration); it has not yet been tested end-to-end with a real UU client.
